# Idea

I have dozens of leads of businesses in Istanbul that don't have a website. They are usually grouped in similar industries. For example, they are either veterinarians or beauty clinics or whatever. My goal is to:

build a website for them
deploy it to Vercel
cold message them on WhatsApp
share that production link to them with a walkthrough video
offer them the code and product if they want, after using the link and video

The problem with this plan is that if I want to build one website for each of those leads, it's going to cost me a lot of time and a lot of tokens. However, they are grouped in similar industries. This is my goal: instead of building 10 beauty clinic websites, what if I build one website for beauty clinics, and for each specific beauty clinic, I go through customization (for example, changing the theme of the website, the name, the header, the address, things like this)?

I want to build one complete standard website with an admin access that gives me the ability to personalize that website for each industry and each business, instead of building that website one by one for a specific business. And if we got the deal and business approved for that website that wants it, I should be able to easily strip down that admin and ship that customized version to that specific client.

Before any coding, I want an artifact of your design, and after my approval, start coding.

stack: nextjs, ts, neon postgres
design: modern, non-generic, very appealing for the taste of istanbul business owner
the language of website itself must be turkish
